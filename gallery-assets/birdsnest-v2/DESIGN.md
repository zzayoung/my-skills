# 鸟巢 V2 · 雨后体验重做

## 用户目标
以用户自己的《汐见商店·雨后街角》为体验基准，替换旧鸟巢版本的工程查看器观感。保留建筑探索、第一人称、Ghost、气象、环境声音和真实米制坐标。不得以“能加载”代替体验完成。

## 已读取的参考
- 用户 Library 中 shiomi-corner-offline.html：默认 orbit；轻量顶部信息与底部浮动工具栏；主按钮走入；观景点、生活化互动；触屏移动摇杆；按需面板。
- 现有 V1.2 截图与 HTML：密集侧栏、常驻坐标/FPS/地图和八键控制区；缺少整体构图、材质层次和渐进探索。
- 2026-10-20 实际读取的 zz.gallery/1 接入约定：同源可信 scene-module、传入 THREE r180、同源源几何预览、独立房间展陈；目录写入与宿主体验验证分开。

## 设计
1. 默认完整模型的雨后黄昏全景。拖拽旋转、滚轮或双指缩放，不要求鼠标锁定，不以欢迎弹窗阻断画面。
2. 底部只保留观景、天气、剖面与主动作。走入后切换为返回模型、Ghost 与观景导航。H 留白。
3. 同一套场景中平滑切换全景、南广场、运动员通道、球场、看台、钢结构与地下研究空间。视角过渡有取消、恢复和安全落点。
4. 钢结构使用有厚度的金属构件；看台具有真实座椅、通道和层次；广场具有铺装、路缘、灯、植被与尺度参照。日夜和天气改变材质、光照、雾与声音，而不只是背景色。
5. 声音需明确用户操作后启用。移动端使用单摇杆与画面拖动，不出现键盘按钮墙。
6. 未经测绘验证的钢节点、地下布局、园林与道路标为研究性重建，不宣称施工级1:1。

## 实施边界
- 创建独立 feat/birdsnest-v2-experience 分支，仅更改 gallery-assets/birdsnest-v2 与对应验证工作流；不修改现有馆藏和其他作品。
- 单文件离线 HTML 内嵌渲染库与程序化资源；运行时无需 CDN、服务器、网络、权限弹窗。
- 场景创建与导航逻辑独立于页面，后续由同一源几何导出 gallery 模块和远景，不做替身模型。

## 验收重点
沙盒禁用鼠标锁定；移动端面板与摇杆不遮住主要模型；切换视角不遗留按键；恢复模型不改变天气；低画质不移除关键建筑；降雨不出现在室内；地下与地面的眼高分离；收起界面后有可见恢复入口；浏览器测试只代表测试环境，不谎报用户设备帧率。
